## 정의될 변수

- coupon_url = "https://coupon.a.prod.service.trickcal.io/"

## 설명

- 사용자가 실시간 알림에 반응하여 터치하면, 앱 내에서 웹뷰로 coupon_url 페이지로 접속한다.
- Input 값을 자동 입력한다. `<input id="UserId">`에는 앱에 등록된 사용자의 UserId 값을, `<input id="CouponCode">`에는 이전의 스크래핑의 결과로 저장돼 알림과 함께 전달된 CouponCode 값을 입력한다.
- 사용자는 그 상태에서 '등록하기' 버튼만 누르면 끝.
